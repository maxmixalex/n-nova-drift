# Controls / 操作

The ship has momentum. Thrust accelerates in the direction it faces; releasing
thrust lets it drift. Turn and fire while drifting to keep space from enemies.

| Action | Keyboard | Touchpad / mouse |
| --- | --- | --- |
| Thrust / 推进 | W, 8, X or Shift; Up in the desktop preview | Aim with the pad while holding a thrust key |
| Turn / 转向 | A / D or 4 / 6; Left / Right in the desktop preview | Move the pointer to the desired heading |
| Brake / 刹车 | S or 2; Down in the desktop preview | Use a brake key |
| Fire / 开火 | Space, Z or Ctrl | Press the touchpad / left mouse button |
| Dash / Blink / 冲刺或闪现 | Tab | Tab |
| Pause / 暂停 | P, Esc, Menu or Doc | Pause with a key |
| Menu selection / 菜单选择 | W / S or 8 / 2 and Enter; desktop arrows also work | Point, then click |
| Select upgrade / 选择升级 | 1 / 2 / 3, or arrows and Enter | Click an upgrade card |
| Reroll / 重掷升级 | R | Click the reroll counter |
| Bank / spend upgrade points / 保留或使用升级点 | U; Esc also banks points on the upgrade screen | Click the pending-upgrades HUD button to spend points |
| Back / 返回 | Esc | Click Back where shown |

Numeric keys 8/2/4/6 and W/A/S/D provide keyboard-only play without relying on
touchpad contact. Moving the touchpad enables pointer aiming; pressing a left
or right steering key returns to keyboard steering.

**Salvo** accumulates missiles while not firing. **Vortex** charges while firing
and releases when firing stops. **Thermal Lance** and charged upgrades also have
hold/release behavior. Optional automatic fire is available in Settings; use
braking to suppress it when preparing a charge or stockpile.

The game saves periodically and when pausing or choosing an upgrade. **Save and
menu** and **Save and quit** preserve the run explicitly. Death clears Continue
for that run while preserving settings and the best score.

**New run mode** in Settings selects Classic or Wild for the next new run. Wild
adds repeatable mutations. Banking points is useful for Ataraxia; press U to
return to the pending upgrades whenever you want to spend them. Changing the
new-run setting does not change the mode of an already running or saved game.
