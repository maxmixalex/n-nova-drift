# nNova 0.2.0 安装与操作

## 直接安装交付包

ZIP 中的 `nNova/` 是计算器安装目录。把其中的 `nNova.tns` 和整个 `data/`
传到安装了兼容 Ndless 的彩色 TI-Nspire，保持两者的相对位置，然后打开
`nNova.tns`。`state/` 保存设置、当前游戏和本地成绩；空目录没有传过去也不要紧，
启动器会自动创建。

```text
nNova/
  nNova.tns
  data/
    nNova.dat.tns
    nNova.gfx00.dat.tns
    ...
    nNova.eng.locale.dat.tns
    nNova.zhs.locale.dat.tns
    ...
  state/
```

交付包已包含转换好的数据，不需要先在电脑运行转换器。电脑用的 `converter/`、
说明和验证文件不需要传进计算器。更新已有安装时替换启动器并完整替换 `data/` 文件夹，以移除旧图像分包，保留
自己的 `state/`。不要把测试存档复制进正式安装。

支持目标是彩色 CX / CX II 系列和兼容的 Ndless r2022 或更新版本。
发布验证在 CX II CAS 的 Firebird 环境中运行，真机帧率仍需以具体设备为准。

## 默认按键

| 动作 | 按键 |
| --- | --- |
| 推进、刹车 | `8`、`2` |
| 左转、右转 | `4`、`6` |
| 开火 | `5` 或 `Ctrl` |
| 技能、手动部署构造体 | `7` 或 `Tab` |
| 打开升级、保留升级点 | `9` |
| 暂停 | `Esc`、`Menu` 或 `Doc` |
| 菜单移动 | `8 / 2 / 4 / 6` |
| 确认、返回 | `5 / Enter`、`Esc` |
| 升级重掷、放逐 | `−`、`Del` |
| 切换按键模式和触摸瞄准 | `0` |

默认是按键模式，轻触或移动触摸板不会抢走按键操作。触摸瞄准模式中，用触摸板
指向并按下开火，同时仍可按 `8` 推进、`2` 刹车。进入菜单、打开升级或切换模式后，
需要松开原来按住的确认键或触摸板，再进行下一次确认，避免连续误选。

“设置 → 控制 → 自定义键盘控制”可以重绑战斗按键。完整行为、保留键和组合操作
见 [CONTROLS.md](../CONTROLS.md)。

## 语言与保存

安装包包含原游戏的 11 种语言。首次启动按系统语言选择，找不到匹配时依次尝试
英语和已安装语言；可以在设置中更改。中文、日文、韩文使用转换后的原游戏字体，
拉丁字母和西里尔字母共享字体组。

暂停菜单的“保存并退出”保存当前游戏并回到标题页。随后选择“继续游戏”恢复。
死亡会结束该次存档，账户进度和本地高分独立保留。默认自动保存策略为暂停或升级时
保存；可以在设置中选择更频繁的保存或仅显式保存。

## 在自己的原游戏目录重新转换

把 `converter/converter.exe` 放到电脑版 Nova Drift 的 `data.win` 同目录，运行：

```bat
converter.exe
```

默认生成 `nNova/data/`，包含图像、字体和全部语言分包。转换器是独立 C++ 程序，
运行时不需要 Python，也不会启动原游戏。Linux 使用同目录附带的 `converter`。

指定源目录和输出目录，并核验转换结果：

```bat
converter.exe "C:\Games\Nova Drift" --output "C:\nNova\data" --verify
```

中文目录名可以直接使用。默认保留所有动画帧，不启用减少动画帧的可选模式。
转换器以随项目验证的 PC 1.2.38.4 数据布局为参考；若其他版本格式不兼容，
应按错误提示检查版本，不要用空包替换可用安装。

## 完成范围

这是针对计算器实现的游戏运行程序，原版画面素材、文本、界面结构和恢复出的玩法规则
由转换数据与原生代码共同呈现。具体玩法覆盖、平台差异和验证结果分别见
[coverage.md](coverage.md)、[ui-parity.md](ui-parity.md) 和发布验证记录。

TI-Nspire 本体没有原电脑版对应的声音播放与 Steam 服务；本地成绩不代表在线排行榜。
